# Abraham Asarel — Portafolio UX & Product Designer

Portafolio personal de Abraham Asarel Cruz, UX & Product Designer especializado en productos digitales complejos, sistemas industriales y experiencias centradas en las personas.

**Sitio en vivo:** _próximamente_

---

## Stack

- [Astro v6](https://astro.build/) — Framework web estático
- [Tailwind CSS v4](https://tailwindcss.com/) — Estilos con tokens de diseño personalizados
- [PhotoSwipe v5](https://photoswipe.com/) — Lightbox de galería de imágenes
- TypeScript (modo estricto)

## Estructura del proyecto

```
src/
├── assets/          # Imágenes optimizadas por Astro
├── components/      # Componentes reutilizables (Header, ImageSlider, MetricCard…)
├── layouts/         # Plantillas base (Layout, ProjectLayout, ConstruccionLayout)
├── pages/           # Rutas del sitio (.astro → URL)
└── styles/          # Design tokens y configuración de Tailwind
public/
└── fonts/           # Fuente tipográfica personalizada (Xanas Wedding)
```

## Comandos

```bash
npm install       # Instalar dependencias
npm run dev       # Servidor de desarrollo en localhost:4321
npm run build     # Build de producción en ./dist/
npm run preview   # Vista previa del build
```
